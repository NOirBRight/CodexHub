# CodexHub 0.2.39

Codex's native Default subagent menu now explains Fast behavior for supported
models, including Luna. The disabled Fast row says “Follows main session”:
current native Codex shares the root session's service tier and cannot apply
Fast independently to its subagents. The menu does not change the main
session's settings or claim that inherited Fast is On or Off.

Native model and reasoning effort remain selectable without connecting to
CodexHub. Gateway-backed Fast switching retains the selected reasoning effort.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Linux and Windows artifacts are built from the same commit.

## 中文

Codex 原生默认子代理菜单现在为 Luna 等支持 Fast 的模型显示说明。
快速模式行标注“跟随主会话”并禁用：当前原生 Codex 与子代理共享主会话
的服务等级，暂不能单独为子代理设置 Fast。此入口不会修改主会话配置，
也不会将未知的继承状态显示为开启或关闭。

未连接 CodexHub 时，仍可选择原生模型和推理等级。Gateway 模型的
Fast 切换继续保留选定的推理等级。

安装后请完全退出 CodexHub（包括托盘进程）再重新打开。
Linux 和 Windows 产物来自同一提交。
