# CodexHub 0.2.9

- Fix Official collaboration continuations failing after parent `spawn_agent` or child `send_message` calls.
- Preserve native V1/V2 tool identities and encrypted argument markers across history and Responses output; keep Chat Completions conversion isolated from unrelated namespaces.
- Select the managed model catalog on explicit Codex connection and preserve the original catalog for disconnect.
- Preserve user catalog edits, removal, and empty values across reconnect/disconnect; retain the recovery backup when the configuration file is missing.
- Correct TOML serialization for catalog paths containing apostrophes or control characters.

Linux and Windows are built from the same release commit. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely (including the tray process) and reopen it to load the new Gateway. Reconnect Codex to select the managed model catalog, then restart Codex to load that catalog. Conversation history does not need to be deleted. The Gateway does not cancel existing child agents when a parent turn fails.
