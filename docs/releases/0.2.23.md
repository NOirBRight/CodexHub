# CodexHub 0.2.23

- Fix continuation after an interrupted Collaboration V2 `wait_agent`: Codex's `aborted by user after ...s` history result is preserved instead of rejected with `malformed_collaboration_result`.
- Keep strict validation for malformed results, unrelated tools, and invalid arguments.
- Add isolated HTTP replay E2E for Chat Completions and Responses upstreams, covering repeated continuation and malformed-result rejection. This tests the Gateway path with a scripted client and upstream, not real Codex interruption gestures.
- Includes all features and fixes from 0.2.22.

Linux and Windows artifacts are built from the same source revision. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new Gateway. Conversation history and provider configuration do not need to be deleted.
