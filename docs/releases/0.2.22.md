# CodexHub 0.2.22

- Clients-page Default subagent pins for OpenCode, ZCode, OMP, and Grok CLI: one injected model plus effort, or empty for CLI default. Each card is independent. Pi and DSH have no picker. The Codex workspace picker is unchanged.
- While a client is connected, Connect, Repair, republish, and save-while-connected write only that client's built-in spawn targets. Disconnect restores that slice plus the Injected Block. Activation stays user-owned.
- A pin whose model has left Client Projection reverts to CLI default without blocking Connect. Invalid effort is rejected without mutating native files.
- After installing, Apply in CodexHub for each pinned client, then restart that client (OpenCode, ZCode, OMP, or Grok CLI) so the spawn targets take effect.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new build. Conversation history does not need to be deleted.
