# CodexHub 0.2.38

Dark-mode dropdowns and other shared UI surfaces now use theme colors, including
menus rendered outside their originating cards. OpenCode 2 model discovery
retains the client's declared reasoning variants.

Native Default subagent settings now preserve ZCode's cached reasoning levels
when a configured model only supplies its identity or name, and allow resetting
only the effort. DSH 0.2 Headless supports independently selecting, saving and
resetting the child model and reasoning effort for both spawn and fork. Native
capabilities remain authoritative; unsupported levels are not invented.

Claude Code's default-subagent entry explains its model-only native contract:
set `effort` in individual agent definitions. Global effort also affects the main
session. Existing agent prompts and main-session settings are preserved.

Quit CodexHub completely, including its tray process, and reopen it after
installation. After changing DSH child settings, start a new Headless invocation.
Linux and Windows artifacts are built from the same commit.
