# CodexHub 0.2.10

- Fix collaboration continuations after Codex clamps short waits, including `wait_agent(timeout_ms=1280)`. Preserve requested values and leave effective duration limits to Codex.
- Accept client-supported optional null arguments and retain parameter-parse and execution failures so a conversation can continue after a failed tool call.
- Cover additional agent lookup, closed-agent, startup and message-delivery failure results without changing them into successes.
- Prevent protocol-conversion errors and request-shape diagnostics from echoing unknown request field names, types, roles or other discriminator values.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new Gateway. Retry the interrupted Codex task; conversation history does not need to be deleted. If a client remains connected to an old Gateway process, restart that client. This release does not change Codex Desktop's Stopped indicator or cancel existing child agents.
