# CodexHub 0.2.25

- Claude Code can retain its native subscription login while using configured Gateway models in the same conversation.
- Fix model switching across native Anthropic Messages, Codex Responses, and third-party Responses/Chat/Messages routes. Conversation text and tool results retain their call associations.
- Fix custom-model validation when an upstream streams a response to a non-streaming request.
- Preserve explicit native model selection and separate default, family-alias, and subagent settings.
- Keep Claude's subscription classifier context on the native route; external routes use a named compatibility adaptation without fabricating permission decisions.
- Report unsupported reasoning-history conversions explicitly, while allowing portable reasoning responses to complete.
- Record connected native subscription usage in the existing Usage Statistics flow.
- Fix Windows Claude batch-shim discovery when executable paths contain spaces or shell metacharacters.

Live Linux source qualification used Claude Code 2.1.283 with Opus 5.5, Codex Sol/Luna, and DeepSeek Flash across all three upstream protocols. Eighteen tool/recall turns and 48 requests passed, including low/max effort, manual compaction and explicit same-session resume. This evidence covers the named models and paths, not every provider-specific capability.

Linux requires Python 3.13+. After installing, fully quit CodexHub (including its tray process) and reopen it to load the new Gateway. Existing conversation files and provider credentials are preserved.

Claude Code 可保留原生订阅登录，在同一会话中切换原生模型、Codex 订阅模型和已配置的第三方模型。修复跨 Messages、Responses、Chat Completions 路由的历史与工具关联，保留完整原生模型 ID 和显式续接，并记录原生订阅用量。Windows 同时修复了路径含空格或 shell 特殊字符时的 Claude 批处理启动。
