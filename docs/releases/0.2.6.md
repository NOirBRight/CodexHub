# CodexHub 0.2.6

Follow-up to 0.2.5. Restart CodexHub after installing so the updated Gateway loads.

- Drop OpenAI-only `web_search.external_web_access` on third-party Responses routes (xAI, Ollama Cloud, Volc, OpenCode Go). Codex Desktop 0.153.4 was forwarding the flag and xAI 400ed with `Argument not supported: external_web_access`. `true` is stripped (those providers already search live); `false` fails closed so cache-only is not silently turned into live fetch. Official Chat and Responses keep the field. `search_context_size` is unchanged.

After installing, quit completely and reopen CodexHub. Do not delete conversation history. If problems occur, return to 0.2.5; do not roll back conversation data merely to roll back the application.
