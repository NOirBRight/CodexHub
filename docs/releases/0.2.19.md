# CodexHub 0.2.19

- Strip Console Go preview-only `search_content_types` and `image_settings` from hosted `web_search` so Codex Desktop image-search fields do not 400 that Responses route. Other providers are unchanged.
- Project catalog reasoning grades into Grok (`supports_reasoning_effort` / `reasoning_efforts`) and Pi/OMP `thinkingLevelMap`, so T3, Pi, and OMP show the effort picker. After installing, Apply in CodexHub and restart Grok, Pi, and OMP so those client files pick up the grades.
- Stamp required Chat `created`, Responses `created_at`, and models `created` timestamps on Gateway wire payloads so T3 Grok serde can read Gateway-synthesized envelopes.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new build. Conversation history does not need to be deleted.
