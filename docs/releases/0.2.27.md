# CodexHub 0.2.27

- Fix the disabled Fast switch for GPT-6-Luna and add GPT-6-Sol Fast. GPT-6-Astra remains supported.
- Cover every currently listed official model advertising Fast: 6 Astra, 6 Sol, 6 Luna, 5.6 Sol, 5.6 Terra, 5.6 Luna, and 5.5. Retain the 5.4 Fast compatibility variant.
- Expose the same supported variants as standalone models in other clients and as Fast choices in Codex subagents, preserving reasoning effort and base capabilities.
- Upgrade the previous default Fast inventory while preserving custom subsets. Explicitly disabled models stay disabled.
- Align the Fast row's state text and icon with the other subagent menu rows.

This continues the stable 0.2.24-based release line without the unpublished Claude coexistence work.
Linux builds natively on Omarchy without root or Docker and requires the host GTK 3, WebKitGTK 4.1, libayatana-appindicator, lsof, Python 3.13+, and a compatible current Arch glibc.
Linux and Windows artifacts use the same source revision.

Quit CodexHub completely (including the tray process) and reopen after installation. Restart Codex after changing the default subagent. Reapply an already-connected third-party client to refresh its model list.
