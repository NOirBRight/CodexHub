# CodexHub 0.2.36

Claude Code client cards now expose the Default subagent picker directly.
Select a native model while disconnected, or a native or Gateway model while
connected. Selecting CLI default clears the override. These changes use the
existing independent subagent settings and preserve the main model,
authentication, and Gateway connection.

Saving closes the Claude picker and prevents duplicate submissions. Failed
saves restore the last saved selection. Restart Claude Code after saving to
apply the setting.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Windows and Linux artifacts are built from the same commit.
