# CodexHub 0.2.17

- Compress Provider editor chrome so the model list gets the dialog: two-column connection fields, a one-row Official usage header (title, five metrics, day/week), and denser single-line model rows.
- Group disabled models under Hidden from picker / 未在选择器中显示 using the existing enabled flag. Toggle does not rewrite order; drag stays inside a group.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new build. Conversation history does not need to be deleted.
