# CodexHub 0.2.14

- Keep Client Projection Display Names on the short wire id so grouped pickers do not show a vendor path.
- Create an OpenCode config on first connect when the file is absent, and treat apply as failed unless the file is written.
- Hold the client connect switch on until the refreshed client list reports the hub route, so it does not flash off after a successful apply.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new build. Conversation history does not need to be deleted.
