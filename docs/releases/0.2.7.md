# CodexHub 0.2.7

Follow-up to 0.2.6. Restart CodexHub after installing so the updated Gateway loads.

- Stop Codex from reconnecting on third-party streams that already produced reasoning or text. An empty `response.completed` after output has started is forwarded, not treated as a disconnect. If the last attempt is still empty, the Gateway writes `response.failed` instead of swallowing the terminal. Official passthrough stays byte-forward; raw chain-of-thought is not mapped onto the summary.
- Drop Official-only Responses transport fields (`include`, `prompt_cache_key`, `store`, `max_output_tokens`, function `strict`) on third-party routes, and clamp unsupported `reasoning.effort` to the model's catalog grade. OpenCode 1.18+ was sending `effort: max` to Muse Spark (supports `xhigh`) and Console Go 400ed.

After installing, quit completely and reopen CodexHub. Do not delete conversation history. If problems occur, return to 0.2.6; do not roll back conversation data merely to roll back the application.
