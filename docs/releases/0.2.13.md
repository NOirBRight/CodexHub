# CodexHub 0.2.13

- Restore a still-mapped GNOME window that is Iconic with `_NET_WM_STATE_HIDDEN` when the user clicks the launcher, AppImage, or tray Show, instead of only setting DEMANDS_ATTENTION (#538).
- Run that Linux restore on the GTK thread with a real X server timestamp; do not present with timestamp 0.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new build. Conversation history does not need to be deleted.
