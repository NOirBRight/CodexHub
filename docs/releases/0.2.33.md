# CodexHub 0.2.33

This release keeps the model-switch image fixes from 0.2.31 and 0.2.32 and
shares one captioned image-lift path for tool-result and mid-conversation
system history. Behavior is unchanged: tool text and call identity stay on
the tool reply, ordered images follow as captioned user content, and boolean
JSON Schema metadata is still preserved while expanding tool references.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Retry the affected conversation after the update.
