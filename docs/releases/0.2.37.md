# CodexHub 0.2.37

OpenCode 2.0.22 completes the real-client CLI cases. Native model discovery
tries `opencode models --verbose` and, when OpenCode rejects that flag, reads
the id-only lines from `opencode models`. OpenCode 2 runs from the case
directory with `--standalone` and `--auto`. OpenCode 1 keeps `--dir` and
`--pure`. If OpenCode 2 exits before the final stop event, a closed text part
finishes the turn only when the stream has no error.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Windows and Linux artifacts are built from the same commit.
