# CodexHub 0.2.18

- Omit unpaired Desktop client-internal tool results (`codex_app` / `mcp__*`) that have Item identity but no Call identity from third-party history, so xAI/Grok generation and compact can continue. The Gateway does not copy `id` into `call_id`. Official passthrough and the client's session file are unchanged.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new build. Conversation history does not need to be deleted.
