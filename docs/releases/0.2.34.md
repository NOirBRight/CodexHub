# CodexHub 0.2.34

This release fixes Pi disconnect when a rollback baseline recorded
`settings.json` as absent and Pi later created user-owned settings. Detach
keeps `settings.json` in place and surgically removes only CodexHub Injected
Block entries from `models.json`, so foreign providers survive.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Disconnect Pi again if it still shows a leftover managed route.

## 中文

本版修复 Pi 断开连接失败：当 rollback baseline 把 `settings.json` 记为 absent，
而 Pi 后来又写出用户自己的 settings 时，旧逻辑会拒绝整次 restore。现在
detach 会保留 `settings.json`，并只从 `models.json` 外科式移除 CodexHub
Injected Block，外来 provider 会保留。

安装后请完全退出 CodexHub（包括托盘进程）再重新打开。若 Pi 仍显示托管路由残留，请再断开一次。
