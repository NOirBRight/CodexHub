# CodexHub 0.2.30

This release builds on 0.2.29 and fixes xAI Responses searches that reuse a
reasoning item ID at different output indices. CodexHub now gives each
reasoning occurrence a stable client-facing ID across streaming events and the
terminal response. Non-streaming responses use the same mapping. Tool call
identity and lifecycle validation remain in force.

The regression fixture comes from a real xAI OAuth search with three reasoning
occurrences sharing one ID, four web searches, and eleven citation annotations.
Fresh search results and citation counts vary. Subsequent turns continue
through the existing third-party reasoning-history conversion.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Reapply an already-connected third-party client to refresh its
model list if needed.

## 中文

本版基于 0.2.29，修复 xAI Responses 网页搜索在不同输出位置复用 reasoning
项目 ID 时，CodexHub 将已完成的响应误判为失败的问题。流式事件、终态和非流式响应
现在对每个 reasoning 项使用一致、稳定的下游 ID；工具调用身份与生命周期校验保持有效。

回归样本来自真实 xAI OAuth 搜索：三个 reasoning 项复用同一上游 ID，包含四次
网页搜索与十一个引用 annotation。新搜索的结果和引用数量会变化。下一轮请求继续
使用现有的第三方 reasoning 历史转换路径。

安装后请完全退出 CodexHub（包括托盘进程）再重新打开。必要时重新应用已连接的
第三方客户端以刷新模型列表。
