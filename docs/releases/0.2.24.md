# CodexHub 0.2.24

- Fix Linux Gateway restart and upgrade handling when the previous process has exited but has not yet been reaped.
- Add native Hyprland/Wayland lifecycle E2E and Arch package-owner detection.
- Declare the lsof runtime dependency used to verify Gateway listener ownership.
- Fix AppImage native Wayland startup and prevent bundled graphics/OpenSSL libraries from conflicting with the host graphics stack and Python.
- Fail closed for experimental owner-only evidence credential copying on non-POSIX systems.
- Make CLI E2E require an actual assistant response instead of echoed prompt text.
- Preserve structured image-generation routing errors for Windows HTTP clients by consuming the bounded request body before route lookup.
- Includes the 0.2.23 interrupted subagent wait recovery and existing Claude Code experimental integration.
- Codex Connect uses the local catalog off the UI thread so the desktop no longer freezes on Connect.
- OpenCode Go model capabilities (vision/thinking and related catalog fields) stay editable and match refreshed endpoint catalogs.
- Omarchy/Linux browser open for provider OAuth uses `omarchy-launch-browser` when present and reports launcher failures.
- xAI subscription auth works without a legacy API key: discovery/probes use the OAuth session, and the subscription editor hides the unused key field.
- Provider model discovery uses the editor draft credentials/URL; Kimi CN resolves `MOONSHOT_API_KEY` when `MOONSHOT_CN_API_KEY` is absent.
- Third-party routes drop optional Codex cache-only `web_search` (`external_web_access=false`) with an explicit model notice instead of rejecting ordinary chat or silently enabling live web access. Forced search still fails closed.

Linux requires host Python 3.13+. Quit CodexHub completely, including its tray process, then reopen it after installing to load the new Gateway.

Linux and Windows artifacts are built from the same source revision. Validation includes native Wayland/tray lifecycle, 125% scaling on the native portable build, GNOME first-launch/portable-upgrade identity, Xvfb input, and four Official CLI combinations.

Muse live testing was explicitly waived by the operator and is not reported as passed. Real-login autostart and IME qualification remain unverified.
