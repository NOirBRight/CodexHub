# CodexHub 0.2.12

- Register Linux login autostart as an XDG desktop file that launches the GUI from the persistent AppImage, portable, or package path, with no `start` argument.
- Write that registration when Launch app at startup is on, including the default-on first run, and retire leftover `codexhub-proxy.service` units.
- Launch the macOS login item as the GUI as well, matching the Windows logon contract.
- Derive short Display Names into grouped Client Projection and compose Flat Labels only on mixed-Provider Gateway lists.
- Omit Official encrypted `agent_message` ciphertext on third-party routes so compact/generation cannot forward undecryptable history.
- Republish Linux tray labels after GNOME AppIndicator races so empty labels do not stick.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new Gateway. On Linux, the first launch writes `~/.config/autostart/` when the setting is on. Conversation history does not need to be deleted.
