# CodexHub 0.2.32

This release fixes another image-bearing history shape in Claude Code model
switching. Version 0.2.31 handled images inside tool results, but automatic
compaction could still send an image in a mid-conversation system message and
receive `text_content_block:image` from the Gateway. The Gateway now keeps
the system text as instructions and carries those images, in order, as
captioned user image content. URL and base64 images are covered through the
Gateway HTTP route.

It also fixes an upstream 400 during automatic compaction of long Claude Code
sessions with connected tools. The Gateway now preserves boolean JSON Schema
metadata while expanding tool references.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Retry the affected conversation after the update.

## 中文

本版修复 Claude Code 切换模型时另一种含图片的历史消息。0.2.31 已处理工具结果中的
图片，但自动压缩仍可能在对话中途的 system 消息里遇到图片，导致 Gateway 报
`text_content_block:image`。现在 system 文本保留为指令，图片按原顺序作为带
来源说明的用户图片内容转发。URL 和 base64 图片均经过 Gateway HTTP 测试。

同时修复长时间 Claude Code 会话连接工具后，自动压缩遭上游返回 400 的问题。
Gateway 展开工具 schema 引用时现在会保留布尔元数据。

安装后请完全退出 CodexHub（包括托盘进程）再重新打开，然后重试受影响的对话。
