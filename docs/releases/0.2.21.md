# CodexHub 0.2.21

- Route OpenCode Go `union-alpha` to Anthropic `/messages`: the model speaks Anthropic protocol with `x-api-key`, so Gateway converts Responses/Chat through the Chat subset instead of sending Responses/Chat upstream (previously HTTP 500 on every call).
- Third-party Anthropic converter: fail-closed unknown Chat fields, `https://` and `data:` images, `tool_choice` mapping, `reasoning_effort` to thinking budgets, thinking/signature round-trip through `reasoning_details`, and catalog output caps when the caller omits `max_tokens`. Codex CLI/App adapter stays deferred.
- Retired catalog ids are removed on catalog apply, discovery, and Gateway load (ADR-0009). `omen-alpha` is retired and replaced by `union-alpha` on OpenCode Go.
- Model settings overlay consumes Escape itself and returns to the Provider page instead of skipping to the workspace homepage.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new build. Conversation history does not need to be deleted.
