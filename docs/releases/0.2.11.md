# CodexHub 0.2.11

- Add Grok CLI as a Provider Injection managed client. Connect injects Gateway models and omits CodexHub's xAI subscription so native Grok stays native. Toast names Grok CLI as the process to restart.
- Write the Codex overlay and managed catalog while Codex is connected, without closing or relaunching Codex. Connection, catalog, and default-subagent saves show a dismissible Restart Codex reminder instead of proxy-restarting Desktop.
- Add a workspace default-subagent picker that writes into the connected overlay and restores on disconnect.
- Keep Grok CLI and other Gateway clients on the transparent provider path, including official system-message sanitizing and Grok/xAI family compact limits.

Linux and Windows require the same validated release source. Linux requires host Python 3.13+; Windows includes its embedded runtime.

After installing, quit CodexHub completely, including its tray process, and reopen it to load the new Gateway. Restart Codex yourself after connecting or changing the catalog so the overlay takes effect. Conversation history does not need to be deleted.
