# CodexHub 0.2.31

This release fixes model switching when an Anthropic Messages conversation
contains images in a tool result. During automatic compaction, the Gateway now
keeps the tool result text and call identity, and forwards each image as a
captioned image message. Parallel tool replies stay paired before the image
messages. Chat Completions and Responses routes are covered.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Retry the affected conversation after the update.

## 中文

本版修复了对话历史中的工具结果含图片时，切换模型触发自动压缩报
`text_content_block:image` 错误的问题。Gateway 保留工具结果文本和调用 ID，
并把每张图片作为带来源说明的图片消息转发；并行工具回复仍先完成配对。
Chat Completions 和 Responses 两种上游路由均已覆盖。

安装后请完全退出 CodexHub（包括托盘进程）再重新打开，然后重试受影响的对话。
