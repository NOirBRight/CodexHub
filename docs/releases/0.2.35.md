# CodexHub 0.2.35

Default subagent settings can now be saved independently of the client's
Gateway connection. Codex, Claude Code, OpenCode, ZCode, OMP and Grok use
their native model and reasoning settings. DSH supports its Headless
spawn/fork defaults; its Web profile has no equivalent setting. Pi 0.80.6
does not expose a native Default subagent setting.

Native selections remain available while disconnected, preserve the main
model and authentication, and survive Gateway reconnection, republishing
and disconnect. Existing connected Gateway subagent selections remain
available. This release also fixes ZCode legacy model identity readback and
Web Bridge saves that reset a subagent or use the client's default reasoning
effort. The fixes shipped in 0.2.31–0.2.34 are retained.

Quit CodexHub completely, including its tray process, and reopen it after
installation. Follow the client restart instructions shown after saving a
Default subagent.

## 中文

现在可以独立于客户端的 Gateway 连接保存 Default subagent。Codex、Claude
Code、OpenCode、ZCode、OMP 和 Grok 使用各自的原生模型与推理设置。DSH
支持 Headless 的 spawn/fork 默认值，Web profile 没有对应设置；Pi 0.80.6
不提供原生 Default subagent 设置。

未连接客户端时仍可选择原生模型，保存会保留主模型与认证，并在重新连接、
重新发布模型和断开连接后保留最新选择。已连接时仍可使用既有的 Gateway
Sub Agent 选择。本版同时修复 ZCode 旧格式模型标识读取，以及 Web Bridge
重置 Sub Agent 或使用客户端默认推理强度时保存失败的问题。0.2.31–0.2.34
已发布的修复均保留。

安装后请完全退出 CodexHub（包括托盘进程）再重新打开。保存 Default
subagent 后，请按界面提示重启对应客户端。
