# CodexHub 0.2.28

Built for Linux and Windows from `d7508997ee15baad2cad08f1993af0b9cfd7ed1e`.

- Combines the 0.2.27 Fast-model and Omarchy packaging updates with Claude subscription coexistence. Native Claude models remain available alongside Codex subscription and configured third-party models; selected models, family mappings and conversation history survive route changes.
- Routes native Claude Messages through Gateway and records real upstream usage, including cache tokens. DeepSeek Flash Chat/Messages/Responses and Codex Luna Responses work across the qualified routes.
- Normalizes Gateway usage provider IDs at write, migration and read time. Existing `official`, `volcengine`, `minimax_cn`, `ollama_cloud`, `opencode_go` and `anthropic_native` rows fold into their exported provider IDs; charts still group by provider ID so unrelated providers remain separate.
- Fixes Windows Codex Desktop detection when the AppX manifest includes a hidden command-runner helper.

Native Haiku usage reached SQLite and the rendered packaged Usage page. Linux Python core passed 3,436 tests; Windows Python core passed 3,560. Linux Rust passed 795 tests (1 ignored), Windows Rust passed 783 (3 ignored), with clippy, frontend/UI contracts, physical pointer E2E, signing and package checks passed. The Windows synthetic real-client contract passed 164/164.

Verified CLI versions (Linux / Windows): Codex 0.157.1 / 0.156.1; OpenCode 1.18.32 / 1.18.32; Pi 0.87.1 / 0.80.6; OMP 18.3.2 / 17.0.3. Linux Claude Code 2.1.283. Windows native Claude and rendered Windows Usage remain unverified on this SHA. Current-version automatic compaction, inherited or pinned subagents, too-long recovery, and every native subscription version are also unverified; these are not claimed as passes.
