# CodexHub 0.2.28

This release combines the 0.2.27 Fast-model and Omarchy packaging updates with Claude Code subscription coexistence.

- Keep native Claude subscription models available beside Codex subscription and configured third-party models. Preserve complete native model IDs, family mappings, selected defaults, and conversation history when switching routes.
- Route native Claude Messages through the Gateway and record actual upstream usage, including cache tokens, in Usage Statistics. Support official Luna and DeepSeek Flash across the four supported CLI clients.
- Correct DeepSeek Chat and Responses conversion, reasoning streams, tool associations, cancellation, and terminal events.
- Fix Windows Codex Desktop detection when its AppX manifest contains a hidden command-runner helper.
- Retain 0.2.27 Fast choices and the native Omarchy Linux packaging path.

The isolated four-client, two-provider CLI gate passed 8/8 on Linux and 8/8 on Windows for the reviewed pre-merge package. Independent Chat passed 2/2 on each OS. The final combined candidate receives its own verification before publication. Verified client versions and detailed evidence are in `docs/evidence/issue-564/`.

Known limits: current-version automatic compaction, inherited or pinned subagents, too-long recovery, and the rendered Windows Usage page have not been verified for every client. The earlier Linux native and Windows resume tests cover their stated versions and scenarios. Fast is a requested tier; the upstream subscription may still report `service_tier: default`.

Quit CodexHub completely, including the tray process, and reopen after installation. Restart Codex after changing its default subagent. Reapply an already-connected third-party client to refresh its model list.
