# CodexHub 0.2.29

This maintenance release carries the 0.2.28 Claude coexistence and canonical Gateway usage Provider ID behavior forward. It corrects the checked-in 0.2.28 release notes and #564 evidence index to match the published, verified candidate. No routing, telemetry, chart grouping or credential behavior changes in this revision.

The four-client × two-provider gate uses Official `gpt-6-luna` and official DeepSeek API `deepseek-flash` on both Linux and Windows, with independent inbound Chat cases. The exact 0.2.29 package results and source SHA are recorded on the GitHub release when publication is complete. The 0.2.28 baseline passed 8/8 CLI and 2/2 Chat on each OS; those historical results are not relabeled as 0.2.29 evidence. The Gateway usage chart continues to group by canonical Provider ID, keeping unrelated Providers separate even when display names match.

Verified CLI versions for the 0.2.28 baseline (Linux / Windows): Codex 0.157.1 / 0.156.1; OpenCode 1.18.32 / 1.18.32; Pi 0.87.1 / 0.80.6; OMP 18.3.2 / 17.0.3. Linux Claude Code 2.1.283. The 0.2.29 candidate must meet the same version and exact-SHA gates before publication.

Known limits: Windows native Claude and rendered Windows Usage, current-version automatic compaction, inherited or pinned subagents, too-long recovery, and every native subscription version are unverified on 0.2.28 and are not claimed as passes for 0.2.29. Issue #564 remains open for that scope. Fast is a requested tier; upstream subscriptions can still report `service_tier: default`.

Quit CodexHub completely, including the tray process, and reopen after installation. Restart Codex after changing its default subagent. Reapply an already-connected third-party client to refresh its model list.

## 中文

本次维护版保留 0.2.28 的 Claude 共存和 Gateway 用量 Provider ID 归一行为，并修正仓库中 0.2.28 发布说明及 #564 证据索引，使其与已发布、已验证的候选包一致。本次未修改路由、用量归集、图表分组或凭据行为。

Linux 和 Windows 的四客户端 × 两提供方门禁使用 Official `gpt-6-luna` 与 DeepSeek 官方 API `deepseek-flash`，独立验证入站 Chat。0.2.29 包的准确结果及源码 SHA 会在发布完成时写入 GitHub Release。0.2.28 历史基线在两个平台各通过 CLI 8/8、Chat 2/2；这些旧结果不会冒充 0.2.29 的实测证据。Gateway 用量图继续按规范 Provider ID 分组，显示名称相同的不同提供方仍保持区分。

0.2.28 基线的实测 CLI 版本（Linux / Windows）：Codex 0.157.1 / 0.156.1；OpenCode 1.18.32 / 1.18.32；Pi 0.87.1 / 0.80.6；OMP 18.3.2 / 17.0.3。Linux Claude Code 为 2.1.283。0.2.29 候选包发布前仍须完成相同版本与准确 SHA 的门禁。

安装后请完全退出 CodexHub（包括托盘进程）再重新打开；修改 Codex 默认子代理后需重启 Codex，已连接的第三方客户端需重新应用一次以刷新模型列表。
