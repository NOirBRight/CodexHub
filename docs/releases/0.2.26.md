# CodexHub 0.2.26

- Add a Fast switch to the default Codex subagent picker, including Luna. Fast keeps the selected reasoning effort and routes requests with the priority service tier.
- Publish hidden Fast aliases with the base model's full capabilities in Codex's static model catalog, so default subagents can start correctly. Planner settings remain inherited across catalog refreshes.
- Expose supported Fast variants as separate models in other clients, retaining the base model’s context, output, and reasoning capabilities.
- Keep Fast eligibility and routing on one shared model registry, with Chinese and English switch labels.

This release is based on stable 0.2.24. It does not include the Claude subscription coexistence changes from the 0.2.25 draft.

Linux and Windows artifacts use the same source revision. Linux requires host Python 3.13+; Windows includes its embedded runtime.

Quit CodexHub completely, including its tray process, and reopen it after installing. After changing the default subagent, restart Codex to apply the setting. Conversation history does not need to be deleted.
